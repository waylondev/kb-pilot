3. Content extraction：按 `tree.json` 中的 `start_line/end_line` 读取源 Markdown，必要时扩展到同级或父级行段。
4. Correction loading：检查 `.kb/memory/corrections/{doc_id}.jsonl`。本次知识库未发现相关 correction 记录，因此本题无 correction。
