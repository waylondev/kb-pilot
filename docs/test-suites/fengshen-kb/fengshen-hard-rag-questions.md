## Q2: 实体消歧 — 多重称号识别

**问题：** 太公望在封神台册封了多少位正神？飞熊先生本人是否在封神榜上？吕尚与姜子牙是什么关系？

### RAG 难度分析

| 难度维度 | 说明 |
|---------|------|
| 实体消歧 | 太公望、飞熊先生、吕尚都是姜子牙的不同称号，分散在不同文档的不同位置，RAG 需要识别它们指同一人 |
| 跨文档关联 | 称号在人物图鉴文档，册封数量在封神榜文档，是否入榜需综合两处信息 |
| 否定推理 | "本人未入封神榜"是否定信息，容易被遗漏 |

### 标准答案

太公望、飞熊先生、吕尚都是姜子牙的不同称号。姜子牙本名姜尚，字子牙，先祖封于吕地故又称吕尚，道号飞熊先生（因周文王梦熊而得遇），周室尊称太公望。

太公望在封神台册封了**三百六十五位**正神。飞熊先生本人**未入封神榜**——他主持封神但自己不在榜上，封神完成后归周辅政，后封于齐，只享人间富贵。

## Q6: 法宝流转追踪 — 番天印的旅程

**问题：** 殷郊叛变时使用了什么法宝？这件法宝原本属于谁？为什么要克制这件法宝需要四件法宝？最终殷郊是怎么死的？殷郊的弟弟殷洪使用了什么法宝叛变？

### RAG 难度分析

| 难度维度 | 说明 |
|---------|------|
| 法宝流转追踪 | 番天印从广成子→殷郊的流转信息分散在法宝文档和战役文档中 |
| 跨文档关联 | 法宝属性在法宝文档，叛变经过在战役文档，人物关系在人物图鉴 |
| 对称结构推理 | 殷郊和殷洪的叛变模式对称（师父传宝→叛变→被克制），需要识别这一模式 |

### 标准答案

1. **殷郊使用的法宝：** 番天印，威力极强的攻击型法宝，祭起后泰山压顶。
2. **原持有者：** 广成子。广成子将番天印传给弟子殷郊助其下山，殷郊叛变后以此印重创周营，广成子本人也无法正面对抗。
3. **克制需要四件法宝的原因：** 番天印威力极大，单一法宝无法抵消，需要四方旗——戊己杏黄旗、素色云界旗、离地焰光旗、青莲宝色旗——四旗合力才能抵消其威力。
4. **殷郊的死因：** 被四方旗克制后，应誓被犁锄而死。
5. **殷洪使用的法宝：** 阴阳镜，原为赤精子持有，传给弟子殷洪。殷洪叛变后以此镜对抗周营，最终被太极图所杀。

## Q16: 边界条件推理 — 落宝金钱能否落太极图
