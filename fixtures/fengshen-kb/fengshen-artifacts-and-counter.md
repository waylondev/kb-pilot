# 封神演义法宝谱与克制关系

《封神演义》中法宝众多，按品阶可分为先天至宝、后天灵宝、普通法宝三类。法宝之间的克制关系是战役胜负的关键因素，往往一件克制性法宝的出现便能扭转战局。法宝的持有者并非固定不变，许多法宝在战事流转中易主，甚至被原主人的弟子反过来用以对抗原阵营，形成复杂的跨阵营对抗格局。

## 先天至宝

### 太极图
- 持有者：太上老君
- 功能：可颠倒阴阳、定住地水火风
- 实战：收服殷洪，使其连人带马化为飞灰

### 混元金斗
- 持有者：三霄娘娘（云霄、琼霄、碧霄）
- 功能：削去仙人顶上三花、胸中五气，废千年修为，可收尽乾坤四海之物
- 实战：九曲黄河阵中困十二金仙，将其修为尽数削去

### 金蛟剪
- 持有者：三霄娘娘
- 功能：太古蛟龙炼化，威力极强，可将仙人截为两段
- 实战：九曲黄河阵中主要攻击手段之一

## 阐教法宝

### 打神鞭
- 持有者：姜子牙
- 功能：二十六节、八十四符印，专打封神榜上有名之人
- 限制：对榜上无名者无效，对修为远超自己者效果大减
- 实战：多次用于对阵截教门人

### 戊己杏黄旗
- 持有者：姜子牙（元始天尊所赐）
- 功能：展开万朵金莲，金光护体，可抵挡混元金斗、番天印等强宝
- 实战：九曲黄河阵中以此旗自保，未被削去三花

### 番天印
- 原持有者：广成子
- 功能：威力极强的攻击型法宝，祭起后泰山压顶
- 流转：广成子传给弟子殷郊助其下山
- 实战：殷郊叛变后以此印重创周营，广成子本人也无法正面对抗

### 乾坤圈与混天绫
- 持有者：哪吒
- 功能：乾坤圈为攻击法宝，混天绫为防御束缚法宝
- 实战：哪吒闹海时以混天绫搅动龙宫，乾坤圈打死巡海夜叉

### 九龙神火罩
- 持有者：太乙真人
- 功能：以三昧真火焚烧敌人，罩住后无法逃脱
- 实战：烧死石矶娘娘

### 捆仙绳
- 持有者：惧留孙
- 功能：捆绑敌人，被捆后无法施展法术
- 流转：弟子土行孙偷取此宝下山助周

### 阴阳镜
- 持有者：赤精子
- 功能：一面照生、一面照死，白面照生人，红面照死人
- 流转：传给弟子殷洪
- 实战：殷洪叛变后以此镜对抗周营

## 截教法宝

### 定海珠
- 原持有者：赵公明
- 功能：二十四颗定海神珠，放出五色毫光，可迷敌目力、乱敌心神
- 实战：赵公明凭此宝独战五位金仙，燃灯道人被逼弃鹿逃亡
- 流转：赵公明死后被萧升、曹宝以落宝金钱落去，转赠燃灯道人

### 落宝金钱
- 持有者：萧升、曹宝
- 功能：可落尽先天至宝以下一切法宝
- 限制：对先天至宝无效，只能落后天灵宝及以下
- 实战：落去赵公明的定海珠和缚龙索

### 钉头七箭书
- 持有者：陆压道人
- 功能：以巫术远程诅咒，二十一日内可害人性命
- 实战：陆压以此术间接害死赵公明

## 诛仙四剑

### 诛仙剑、戮仙剑、陷仙剑、绝仙剑
- 原持有者：通天教主
- 功能：诛仙阵核心，四剑悬于四门，非四位圣人合力不可破
- 流转：破阵后四剑分别被广成子（诛仙剑）、赤精子（戮仙剑）、玉鼎真人（陷仙剑）、道行天尊（绝仙剑）摘取

## 法宝克制关系总览

| 被克制的法宝 | 克制法宝 | 克制方式 |
|------------|---------|---------|
| 混元金斗 | 戊己杏黄旗 | 金莲护体，金光抵挡 |
| 番天印 | 四方旗（戊己杏黄旗、素色云界旗、离地焰光旗、青莲宝色旗） | 四旗合力抵消番天印威力 |
| 定海珠 | 落宝金钱 | 直接落去法宝 |
| 风吼阵飓风 | 定风珠 | 定住飓风 |
| 殷洪阴阳镜 | 太极图 | 太上老君以太极图收服 |
| 殷郊番天印 | 四方旗 | 广成子借四方旗克制 |
| 闻仲 | 通天神火柱 | 云中子以火柱困烧 |
