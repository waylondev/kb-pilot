## 结论

- **kb-ingest**：结构层 100% 正确，LLM 填充扎实支撑了后续高路由质量；脚本只做结构、语义全交 LLM，符合设计取舍。

- **适用域声明**：该表现成立的前提是「结构良好 + 高质量 + 规模适中（百篇级）」；超大库、实时低延迟场景的边界需扩容测试，未在当前范围内验证。
